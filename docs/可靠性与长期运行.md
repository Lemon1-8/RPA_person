# 可靠性与长期运行

## 草稿、修订和日志

草稿与正式保存版本分别存储。编辑停止 1 秒后保存草稿，连续编辑最长每 5 秒刷新；退出程序前等待界面刷新草稿。无效 JSON 字段文字也可恢复。启动后由用户选择恢复或放弃，保存版本冲突时恢复为副本。

保存流程前归档当前修订；恢复历史内容会创建新修订。首次升级从当前保存版本开始，没有对应历史的旧版本不会被虚构。

日志按运行分页读取，每页默认 200 条，支持搜索、加载更早记录和导出 JSONL。旧日志按原记录读取，损坏行显示数量且保留原文件。每次运行尝试保存独立快照。

“忽略失败”仍允许流程完成，但会累计警告并显示“完成但有警告”。成功重试与正常 Catch 不计警告。CLI 成功退出码保持为 0，同时输出警告摘要。

草稿、日志和运行记录写入失败时显示持续提示，修复访问权限或空间后可重试。正式保存失败需用户重新保存，以保留修订冲突检查。

## 采集与编辑

高级采集与校验指令默认折叠，可展开或通过“高级”分类查找。网页元素库支持在保留会话中拾取、重新验证、高亮和重命名；拾取会拦截普通业务点击并保存逐层 iframe 定位，取消或页面导航后清理监听。保存后当前指令直接使用 `@元素名`。

步骤列表提供搜索和批量复制、删除、移动；移动完整子树且禁止移入自身后代。`Ctrl+S` 保存当前流程。变量可展开查看或预览前 100 行。脚本检查只编译/解析源码，不执行业务代码，不自动安装依赖。

整流程运行前执行参数和环境检查，确定错误阻止启动；运行时引用给出提醒并在执行时再次校验。Python 检查明确使用 UTF-8，兼容 Windows 默认编码与中文源码。

第一阶段：`tests/workbench-store.test.ts` 覆盖草稿、修订、5001 条历史日志、损坏行和保存故障重试；`scripts/smoke-reliability.mjs` 验证真实 Electron 的无效 JSON 草稿恢复和修订记录。
